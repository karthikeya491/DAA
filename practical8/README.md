## Time and Space Complexity

- **DFS:** Time complexity `O(V²)` and space complexity `O(V)`.
- **BFS:** Time complexity `O(V²)` and space complexity `O(V)`.

Here, `V` represents the number of vertices. The time complexity is `O(V²)` because the program uses an adjacency matrix to check the neighbors of each vertex.
